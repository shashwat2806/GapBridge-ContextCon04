# Patch Management Standard

## Patch intake
IT reviews vendor security advisories when they arrive in the shared support inbox. Employees can report suspected vulnerabilities to the helpdesk.

## Assessment and deployment
Supported laptops receive operating-system updates once each month. Critical updates should be installed promptly, but the standard does not define a risk scale, deadline, or exception process.

## Software controls
IT maintains a list of approved applications for company devices. Unapproved software may be removed after it is discovered. No configuration baseline or vulnerability validation record is required.

## Exceptions
The application owner may delay an update when it would interrupt a release. The owner records the reason in a ticket, but no one reviews the exception later.
